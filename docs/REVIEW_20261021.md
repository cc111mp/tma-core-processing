# Deep correctness review — 21 October 2026

The second audit found defects beyond the original test coverage. Version 0.3.1
repairs the reproduced failures below. Passing tests is evidence for the tested
contracts, not proof that arbitrary inputs or future acquisitions are bug-free.

The review covered registration geometry and resampling, illumination and mosaic
measurements, native coverage, raw/input boundaries, mutation during execution,
manifest publication, historical report freshness, and Python/CLI contracts.
Separate reviewers checked each other's repairs. Probes used disposable
synthetic data; real NAS archives and transfer jobs were not modified.

## Confirmed defects and repairs

| Priority | Reproduced defect | Repair and regression evidence |
| --- | --- | --- |
| P1 | A run/cache root above `raw_root` passed preflight; generated stage folders could then fall inside the immutable archive. Nested writable-tree symlinks could also redirect stage/report writes. | Reject both ancestor directions and pre-existing output/cache symlinks before writing. Boundary tests exercise the colliding folder names and report/stage aliases. |
| P1 | Raw or H&E replacement after initial hashing could be consumed while stage provenance retained the original hash. Disabled/evicted tile caches also accepted replacements. | Bind SHA256 to the opened source and pin filesystem identity through decode, stages and cached-artifact verification. Tests mutate raw, H&E and external assets during each boundary and verify failure isolation. |
| P2 | Path-only stat/hash/stat checks could associate a transient alternate file's hash with the restored original file's identity. | Verify opened-descriptor identity before and after hashing and compare it with the pathname. An independent cross-review supplied the transient-alias regression. |
| P2 | Central node differences labelled a reachable tapered residual map fold-free even though bilinear cells had negative Jacobians. | Check all bilinear-cell corners and nearest-extension edge/corner regions. The reproduced minimum changes from +0.470 to −0.061, detecting 16 folded cells and rejecting that warp. |
| P2 | Valid float grayscale H&E in camera counts was clipped as if normalized; premature float32 conversion erased representable float64 contrast. | Use an encoding-independent grayscale structural proxy and retain float64 until normalization. Integer/count/normalized/high-offset/tiny-range tests compare working views, matching, previews and original native exports. |
| P2 | A constant float32 correction such as 20.1 had a rounded nonzero standard deviation and produced NaN Pearson measurements. | Use float64 variance and finite-correlation guards. Constant corrections retain collapse evidence and serialize strict finite QC records. |
| P2 | Reciprocal gain diagnostics overflowed for valid positive subnormal float32 fields even when corrected pixels were finite. | Calculate diagnostic reciprocals in float64. A full AF run completes with finite native output and explicit collapse flags. |
| P2 | Historical pair reports missed changes to external core configuration, model/runtime identities and referenced residual fields. | Include those dependencies in pair compatibility. Changed observations become STALE; unavailable optional prerequisites remain isolated from AF processing. |
| P2 | Folder/transfer imports could replace a concurrently created manifest. Transfer imports could publish invalid JSON manifests or write inside raw inputs. | Share exclusive publication across all importers; validate before publishing and enforce the raw boundary. | P2 | Different FOV path strings could resolve to one source image, assigning it multiple native tile identities. | Reject duplicate resolved paths within each core, including relative, absolute and symlink aliases. |


The final verification counts and artifact identities are recorded in
[VALIDATION.md](VALIDATION.md) and the audit directory's `verification.json`.
The earlier 0.3.0 verification remains historical evidence, not a substitute for
the checks of these repairs.

All scientific quality states remain advisory. Geometry QC does not reorder or
repair FOV positions. Positive map Jacobians describe the computed coordinate
map; they do not rule out physical tissue folds or establish dense anatomical
correspondence. Real paired-section benchmarking, acquisition-specific
acceptance thresholds and absolute fluorescence preservation remain unvalidated.

Inputs and fitted assets must remain immutable during a run. Descriptor-bound
hashing and stage identity checks detect the tested replacements and in-place
changes; they are not a transactional filesystem snapshot or a defence against
adversarial replace-and-restore swaps during an external decoder's read. Writable
run/cache trees are application-owned, with no external concurrent writers.
The local run lock coordinates this application on one workstation.
