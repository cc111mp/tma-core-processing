# Common-error correctness review — 22 October 2026

Version 0.4.1 reviews the initial targets: uneven illumination/GRID, stitching
errors, focus/detail problems and missing/corrupt declared inputs. The code
retains advisory evidence for the first three and explicit integrity failures
for invalid declared inputs. It does not classify all artifacts or reproduce
the historical Excel decisions without a calibrated reference set.

## Confirmed defects and repairs

| Area | Reproduced problem | Current behavior |
| --- | --- | --- |
| Raw TIFF integrity | A fresh SHA did not prevent a second plane from being silently ignored, an empty TIFF from aborting preflight, or missing strips from decoding as zeros. | Require one raw camera plane; validate segment-table length, positive offsets/counts and stored bounds; contain bad-input preflight errors to the affected input. Runtime decoding checks compressed contents. |
| Referenced TIFF pixels | OME metadata could resolve pixels from a different, unverified file despite hashing the declared source. | Shared native readers reject external OME pixel references before series resolution, with multifile resolution disabled. This also covers H&E and correction fields. Self-contained OME and supported H&E pyramids remain available. |
| Focus numerics | A one-count texture over a bright uint16 offset produced a different normalized detail score. | Center in float64 before Gaussian/Sobel operations. Constant, insufficient-variance and nonfinite windows retain explicit unavailable reasons. |
| Tile summaries and display | A regular percentile/preview stride could sample only zeros from a half-bright periodic native image. | Native uint16 histograms determine per-FOV and pooled tile-display limits; FOV grid previews use area averaging. |
| Sampling disclosure | Sparse window strides left native pixels unmeasured without a coverage receipt. | Save native window/interior bounds and their geometric union, including unavailable windows. Never interpret this as valid-focus or tissue area. |
| Overlap geometry | DC offsets distorted phase correlation; one-directional patterns could produce apparently supported full 2D vectors. | Center/normalize phase inputs; retain directional-degeneracy exclusions and bounded exact-symmetry checks with reasons. These safeguards do not prove a unique match. |
| Tile-pitch fits | Small count rescaling could turn a genuine harmonic fraction into zero. | Normalize the fit before solving, then return amplitudes in original count units. |
| Measurement availability | Low-signal seam measurements and local-only periodicity fits could disappear from the artifact summary. | Retain all measurable seam strata, count distinct seams separately, and show global/local projection counts and links. Failed stages cannot present retained fits as current assessed evidence. |

## What each initial target supports

| Review target | Available evidence | Limit |
| --- | --- | --- |
| Uneven illumination / GRID | Raw-selected overlap comparison; native signal spans and exact collapse flags; seam tails; native global/local tile-pitch fits. | Signal compression, anatomy and alignment can influence results. No GRID probability or artifact-area mask is inferred. |
| Stitching | Overlap residuals and correlation; exclusion reasons; native overlap crops; boundary/control cuts. | Texture and repetitive patterns can be ambiguous. Supplied geometry and FOV order remain unchanged; no automatic repair is performed. |
| Out of focus | Native local-detail windows, unavailable reasons, sampling coverage and raw FOV evidence. | The metric is not a calibrated blur detector. Smooth anatomy, noise and weak signal confound it; no blurred-tissue fraction is reported. |
| Missing / corrupt inputs | Manifest-listed hashes, TIFF plane/profile checks, segment validation and runtime decoding. | A manifest cannot prove that an unlisted physical core/FOV was acquired. Header-only preflight cannot certify compressed pixel contents. |

## Verification and remaining evidence

The audit uses synthetic failure reproductions, positive controls, independent
code review, full package tests, an AF–H&E workflow through both public
interfaces, native-output equivalence and wheel execution outside the checkout.
The completed counts and artifacts are recorded in
`/mnt/4TB_hdd/PhoMedics/qc/work/common_error_audit_20261022/verification.json`.
The guide is also checked for executable syntax, internal links, page layout,
PDF pagination and readable rendering. These checks establish bounded software
evidence, not an expert-label agreement rate or a claim that no bugs remain.

Before turning measurements into accept/reject decisions, link expert labels
to the exact reviewed image versions, define the rubric, separate related
slides/acquisitions between calibration and evaluation, and evaluate held-out
performance. Physical folds, dust and generic artifact segmentation remain
outside the initial validated scope. See [stage QC](STAGE_QC.md) for the current
measurement contract and [methods](METHODS.md) for assumptions and limits.
